# Каталог карт ETS2, schema 1

`ets2.json` распространяется отдельно от кода. Для штатного сервиса опубликуйте этот файл в `main` репозитория. Лаунчер обращается к raw.githubusercontent.com; можно указать другой HTTPS-источник в интерфейсе. Повышайте `revision` при каждом изменении каталога, чтобы свежая комплектная копия могла заменить старый кэш.

Каждая запись содержит постоянный `id`, название, автора, регион, описание, `source`, проверенный `release`, зависимости, конфликты, порядок `after` и модуль карты. `support: true` обозначает служебный компонент. Самостоятельная карта использует собственный `/map/*.mbd` и отдельную сборку.

`source.kind` выбирает адаптер (`promods`, `scs_forum`, `truckymods`, `poland`, `roextended`). CSS `selector` ограничивает блок релиза; первая группа `version_pattern` извлекает версию. `browser_url` задаёт бесплатную страницу загрузки отдельно от страницы публичных метаданных. Не добавляйте платёжные URL как автоматическую загрузку. Необязательные `date_pattern`, `size_pattern`, `requirements_pattern` также используют первую группу. `stop_before` исключает исторический текст и ссылки старых выпусков из блока релиза.

`release.game_versions` содержит совместимые префиксы ETS2, например `1.61`, без предположений о следующей ветке. `dlcs` содержит реальные имена файлов без `.scs`; Nordic Horizons — `dlc_polar`. Пакеты в `packages` перечисляются **снизу вверх по приоритету**. Каждое правило должно найти хотя бы один файл; `optional: true` разрешает его отсутствие. Указывайте отдельные обязательные правила для частей карты, чтобы неполное скачивание не считалось готовым. Сохраняйте имена персональных DEF.

`release.downloads` предназначен для разрешённых публичных прямых HTTPS-ссылок с `filename` и необязательным `sha256`. Оставьте массив пустым, когда нужен браузерный сценарий автора. Временные токены авторизованной сессии публиковать нельзя. Приложение заново проверяет версию на источнике перед загрузкой; новый номер релиза требует отдельного обновления проверенных правил.

`connections` применяются при наличии всех `when`. `add` автоматически добавляет коннекторы, а `versions` фиксирует проверенные версии всех участников. `verified: false` блокирует сочетание с текстом `note`; это применимо также к тройным сочетаниям, даже если парное соединение разрешено. Не объявляйте проверку всей смеси карт на основании одной парной стыковки.

Текущая подтверждённая парная стыковка ProMods 2.84 + RusMap 2.61 использует [коннектор kworey](https://beta.truckymods.io/euro-truck-simulator-2/map-patches/promods-rusmap-connector-626771). Для сочетаний с RoExtended и Poland Rebuilding нужны соответствующие варианты соединений; непроверенные сочетания заблокированы. Десять карт в каталоге не означают, что все десять можно включить одновременно.

Проверка после редактирования: `scripts/cargo.ps1 test --locked --test map_manager`, затем `ets-launcher.exe --map-sources <report.json>`. Не заменяйте рабочий кэш недоступной страницей или неопознанной разметкой. Никакие скрипты, команды или исполняемые файлы из JSON не запускаются.

Поля `source.game_pattern` и `follow_releases` позволяют получать текущую версию и ветку ETS2 со страницы автора. `download_selector`/`download_pattern` выбирают текущий файл на странице; TruckyMods использует кнопку `/download/latest`, а не первую историческую загрузку. `download_api` — только относительный путь API того же сайта, `download_wait_seconds` — предусмотренное сайтом ожидание (до 120 секунд). `supplements` задают дополнительные файлы с авторской страницы (page, selector, pattern, filename); `{version}` заменяется текущей версией. Имена из Content-Disposition проверяются и сохраняются, временные ссылки не кэшируются.

`source.mirrors` задаёт альтернативные ссылки, извлекаемые перед скачиванием с авторской `page` по `selector` и `pattern`. `{version}` и `{version_compact}` заменяются текущей версией с точками и без них. `same_row: true` дополнительно читает публичные ModsFire/Sharemods-ссылки из той же строки таблицы, где найден текущий архив. Это позволяет выбрать бесплатное зеркало вместо формы входа другого сервиса, не зашивая адрес файла в EXE. Ограничивайте селектор публикацией автора и шаблон текущим релизом. Ошибка HTTP 403, ссылка Login в шапке и реклама Premium не считаются требованием регистрации.

`coverage` содержит summary, source, fictional и areas. Каждая area — трёхбуквенный ID страны Natural Earth, необязательный bounds `[west,south,east,north]` и rework. Это приблизительная региональная схема. `fictional: true` не задаёт реальные координаты.

`require_verified_connections` запрещает неподтверждённые пары; `compatibility_family` объединяет официальные компоненты одной семьи. `before` задаёт явный приоритет ниже другой карты независимо от зависимости установки — например, The Great Steppe ниже ProMods Europe. Скрытые конфликты и тройные правила всё равно проверяются.

Для коннекторов с однозначным номером релиза можно задать `connections[].live_versions`: `source` — ID коннектора, `pattern` — полный шаблон версии, `bindings` — ID карт и номера групп. Лаунчер извлекает требования из текущей версии, опубликованной автором, и разрешает только точное совпадение всех участников. Изменённый формат, ошибка источника или несовпадение версии оставляют установку заблокированной. Произвольный новый коннектор или неизвестная тройная стыковка так не добавляются.
