# Сборки Quper — проверка 31 октября 2026

Активный раздел сборок заменён каталогом [Quper Simulator](https://qupersimulator.ru/). Старые библиотеки на диске не удаляются. Отдельные карты, карта регионов и JSON-каталог совместимости больше не загружаются интерфейсом.

## Источники

- URL JavaScript-каталога обнаруживается в HTML главной страницы: имя файла с хешем не зашито в EXE. Считываются только данные объектов; код сайта не выполняется.
- Название, обложка, игра, версия, дата и ссылка на таблицу берутся из объекта сборки. Теги `boosty` и таблицы на Boosty исключаются.
- Google-таблица читается через публичную HTML-выгрузку `gviz/tq?tqx=out:html&gid=...`. Сохраняется именно `gid` выбранной сборки; рекламные ссылки, история изменений и готовые профили из подвала таблицы не попадают в очередь файлов. Пустые объединённые ячейки наследуют ссылку общего архива.
- Для сборок с авторасстановкой порядок берётся из `/profiles/<версия игры>/<id сборки>.txt`; проверяются количество и непрерывная нумерация `active_mods`. Обязательные пакеты определяются этим списком. Для архивных выпусков без авторасстановки используется обратный порядок строк авторской таблицы.
- Автоматические HTTPS-переходы на Boosty запрещены также для ссылок внутри бесплатных таблиц. Отсутствующая публичная ссылка отображается как необходимость импорта.

## Файлы и окружения

Прямые файлы загружаются в отдельный временный файл и публикуются после полного ответа. HTML, исполняемые файлы и опасные имена не принимаются. Используются имена автора из `Content-Disposition`, включая UTF-8. Поддерживаются публичные формы Sharemods, ModsFire, WDFiles и Google Drive, текущая загрузка TruckyMods и явные файловые ссылки на авторских страницах. Изменившийся или закрытый протокол возвращает понятную ошибку и браузерный сценарий.

Встроенный WebView2 автоматически выполняет обычные бесплатные шаги Sharemods/ModsFire. Вход, CAPTCHA и другие проверки сайта не обходятся. Готовые загрузки проверяются и импортируются, а очередь переходит к следующему источнику после получения необходимых пакетов. Можно пропустить страницу, остановить очередь или импортировать локальные архивы.

Ожидание CAPTCHA проверяет поля ответа reCAPTCHA, hCaptcha и Cloudflare Turnstile. После решения виджет может оставаться на странице; это больше не останавливает очередь. Пустое поле Turnstile останавливает отправку формы даже при виджете внутри закрытого Shadow DOM, а истечение ответа снова включает ожидание. Скрытые формы входа и невидимые значки reCAPTCHA не блокируют загрузку. Код выполняет действия только в главном документе и не вмешивается во фреймы проверки.

Проверки внутри страницы распознаются независимо от её заголовка. При повторении или ошибке проверки кнопка **Внешний браузер** использует браузер из настроек, передаёт метку `#truck-launcher` и включает импорт из выбранной папки загрузок только после успешного запуска. Cloudflare указывает [ограниченную поддержку встроенных браузеров](https://developers.cloudflare.com/cloudflare-challenges/reference/supported-browsers/); успешное решение любой проверки внутри WebView2 гарантировать нельзя.

Каждая версия сборки имеет отдельные загрузки, пакеты, журнал состояния и `home`. Повторные строки общего архива не создают повторной загрузки уже полученных пакетов. Пакеты проверяются по SHA-256, ZIP — также по CRC; составные архивы безопасно распаковываются встроенным 7-Zip. Неполная сборка не получает готовое окружение и кнопку запуска. Применение создаёт новый локальный профиль; повторная проверка сохраняет его карьеру. Созданный профиль и отметка готовности сначала размещаются в staging, затем публикуются одним переименованием папки.

ETS2 использует `Euro Truck Simulator 2` и `/map/europe.mbd`, ATS — `American Truck Simulator` и `/map/usa.mbd`. Запуск через Steam сохраняет нужный app ID; `-homedir` указывает на родителя папки документов. Проверяется версия именно выбранного исполняемого файла игры.

## Воспроизведение

```powershell
.\scripts\cargo.ps1 test --locked --test quper --lib
.\scripts\cargo.ps1 clippy --all-targets --locked -- -D warnings
node --test tests/browser_captcha.cjs
```

Небольшие реальные фрагменты каталога и таблицы находятся в `tests/fixtures/quper-*`. Тесты работают с временными папками и маленькими пакетами: ETS2/ATS, порядок модов, продолжение неполной сборки, сохранность карьеры, общий архив, отмена, конфликт файлов, небезопасные имена, HTML вместо архива и обрыв HTTP.

`browser_captcha.cjs` без внешних зависимостей проверяет жизненный цикл ответов обоих скриптов и отправку формы: ожидание, решение при оставшемся виджете, истечение, закрытый Shadow DOM, скрытые формы и невидимые значки. Это локальные сценарии с тестовыми полями, а не автоматическое решение настоящих CAPTCHA. В Rust отдельно проверяется сброс состояния при отмене и игнорирование запоздалых результатов предыдущего WebView.

Проверки сайта выполняются отдельно от тестов:

```text
ets-launcher.exe --quper-catalog <report.json>
ets-launcher.exe --quper-plan gold-russia-map-161 <report.json>
ets-launcher.exe --quper-file <public-url> <download-folder> <report.json>
```

`--quper-download` получает настоящую сборку и может использовать десятки гигабайт. Полная загрузка всех сборок и дорожный прогон в игре не входят в автоматические тесты. Бесплатные таблицы могут содержать обязательные моды с единственной ссылкой на Boosty или авторский сайт с регистрацией; такие файлы требуют пользовательского импорта и не пропускаются при проверке полноты.
