# Шрифты интерфейса

Статические экземпляры (веса 400/600/700/800 для Manrope, 400/700 для JetBrains Mono) получены из файлов Google Fonts, вложенных в макет редизайна, с помощью `fontTools.varLib.instancer`. Подмножества: латиница (`*-lat-*`) и кириллица (`*-cyr-*`).
